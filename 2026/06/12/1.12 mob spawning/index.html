1.12 Mob Spawning

​ At each tick, the game first identifies the areas eligible for mob spawning. It begins by iterating through all players and adding all available chunks within a range of 128 blocks (including loaded chunks) to the list. The game then verifies whether it has exceeded the mobcap. If it has not, it shuffles the chunks added to the list and starts iterating through them. For each chunk, the game selects a random position and checks whether it is occupied by a solid block.

The y-coordinate is chosen following the selection of the x and z coordinates.

The game obtains the highest block at coordinates (x,z) and rounds the y+1 coordinate up to the highest position of that subchunk. Then, using this y coordinate as the upper limit, random values are selected from it to determine the final position $ (x, y, z)$. If there is no solid block at this location, then we will proceed to pack spawning.

Each selected position $ (x, y, z)$ will perform pack spawning 3 times. Each pack spawning will take the previous position (xi,yi,zi) as the starting point and move a random number from 0 to 5 blocks in the x and z coordinates, respectively, to select the next position. The size of the pack that the game attempts to spawn is a random number from 1 to 4.

Subsequently, the game validates whether any player is located within a 24-block radius of (xi,yi,zi) , while ensuring the coordinate is situated more than 24 blocks from the world spawn point.
